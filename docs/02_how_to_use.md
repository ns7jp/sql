# 02. 演習の進め方

## 全体の流れ

演習は `exercises/` フォルダに、レベル1〜6の6ファイルで用意されています。
上から順番に取り組むことをおすすめします。後のレベルほど、前のレベルの知識を前提にしています。

| ファイル | 内容 | 目安時間 |
|---|---|---|
| [level1_select_basics.md](../exercises/level1_select_basics.md) | SELECTの基本（WHERE, ORDER BY, LIKEなど） | 1〜2時間 |
| [level2_aggregate_groupby.md](../exercises/level2_aggregate_groupby.md) | 集計とグループ化（COUNT, SUM, GROUP BY, HAVING） | 1〜2時間 |
| [level3_join.md](../exercises/level3_join.md) | テーブルの結合（INNER JOIN, LEFT JOIN, 自己結合） | 2〜3時間 |
| [level4_subquery.md](../exercises/level4_subquery.md) | サブクエリ（WHERE句、EXISTS、相関サブクエリ） | 2〜3時間 |
| [level5_dml_transaction.md](../exercises/level5_dml_transaction.md) | データ操作とトランザクション（INSERT/UPDATE/DELETE） | 1〜2時間 |
| [level6_advanced.md](../exercises/level6_advanced.md) | 実務でよく使う応用（VIEW, INDEX, ウィンドウ関数） | 2〜3時間 |

合計でおよそ10〜15時間程度を想定していますが、理解を優先して自分のペースで進めてください。

## 1問の取り組み方

各問題は、次のような「隠しながら段階的に確認できる」構成になっています。

1. **問題文を読む** — まずは自分でSQLを書いてみましょう。
2. **実際にSQLを実行してみる** — [docs/00_setup.md](00_setup.md) の手順で立てたMySQLに接続し、
   実際にSQLを打ち込んで結果を確認します。頭の中だけで考えず、必ず手を動かすことが上達の近道です。
3. **詰まったら「💡 ヒントを見る」を開く** — GitHub上のMarkdownでは、
   `<details>` の部分はクリックすると開閉できる折りたたみ表示になります。
   いきなり答えを見るのではなく、まずヒントだけを参考にもう一度考えてみましょう。
4. **「✅ 模範解答と解説を見る」で答え合わせ** — 自分の書いたSQLと模範解答を見比べて、
   結果が合っているか、書き方に違いがあれば何が違うのかを確認します。
   模範解答は「唯一の正解」ではありません。同じ結果を得られるなら別の書き方でも正解です。
5. **「覚え方のポイント」で理解を定着させる** — 丸暗記ではなく、
   「なぜそう書くのか」を自分の言葉で説明できるようになることを目指しましょう。

## 学習のコツ

- **書き写すだけで終わらせない**：模範解答をコピペするだけでは身につきません。
  一度閉じて、何も見ずにもう一度自分で書けるか試してみましょう。
- **エラーを恐れない**：SQLはエラーメッセージが具体的なので、
  「どこが間違っているか」を読み解く練習にもなります。エラーが出たら、
  まずメッセージをよく読んでみましょう。
- **WHERE句をつけ忘れたUPDATE/DELETEに注意**：[レベル5](../exercises/level5_dml_transaction.md) では、
  誤って全件を書き換えてしまう事故を防ぐ考え方も学びます。
  不安なときは `SELECT` で対象範囲を確認してから `UPDATE`/`DELETE` を実行する習慣をつけましょう。
- **詰まったら[docs/03_sql_cheatsheet.md](03_sql_cheatsheet.md)を見返す**：
  SQLの実行順序や構文の一覧をまとめた早見表です。

## ポートフォリオとしての使い方

この演習パックは、未経験からサーバー構築エンジニアを目指す方が、
「SQLの基礎を体系的に理解し、実際に手を動かして検証できる」ことを示すためのポートフォリオです。
面接や書類選考でこのリポジトリを見せる際は、以下のような点をアピールできます。

- 単なるSQL文の暗記ではなく、`docs/01_schema.md` のようにテーブル設計を理解した上で
  問題を解いていること
- `docker/docker-compose.yml` を使って、自分でデータベースサーバーを構築・起動できること
- README や本ドキュメントのように、他の人が読んでも迷わないドキュメントを整備できること

演習を終えたら、`exercises/` の中から自分が特に理解が深まったと思う問題をいくつか選び、
「なぜその書き方にしたか」を自分の言葉で説明できるようにしておくと、面接でも役立ちます。
